### Foundry | AI Agent Workspace & Product Thinking OS
* **Architected and developed** a full-stack autonomous workspace designed to capture, structure, and autonomously stress-test complex ideas and technical architectures.
* **Designed an extensible agent architecture** utilizing the **Model Context Protocol (MCP)**, enabling LLMs to dynamically discover and interface with external datasets, APIs, and computational tools for grounded reasoning.
* **Built an autonomous agent pipeline** integrating a custom Python microservice to execute deep market research, run automated SWOT experiments, and generate reproducible Markdown reports.
* **Integrated Google Gemini API** to create an AI Co-Pilot capable of autonomously expanding raw concepts into scoped MVPs and technical specifications, showcasing prompt engineering and model steering capabilities.
* **Engineered a responsive frontend** using React 19, Vite, Tailwind CSS 4, and Framer Motion, featuring a rich Markdown-based research environment and a keyboard-first command palette (`⌘K`).
* **Developed a robust Node.js/Express backend** managing a custom JSON database, RESTful API endpoints, and asynchronous progress tracking for long-running agent workloads.
